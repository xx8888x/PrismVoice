# 稜鏡 PRISM — 客戶展示專區 (Client Demo)

本目錄為專為客戶、業主與展示所設計的**純靜態、零外部相依**互動式原型展示站點。

---

## 🚀 快速開啟方式

本展示專案具備完整離線與靜態瀏覽相容性，客戶或展示人員**無需安裝 PHP、Node.js、Composer 或 MariaDB**：

1. **直接開啟**：
   - 雙擊開啟 [`index.html`](file:///d:/稜鏡媒體網站/Demo/index.html) 或以任何主流瀏覽器（Edge, Chrome, Safari, Firefox）開啟。
2. **本機伺服器開啟（選用）**：
   - 若您習慣透過本機 Web 伺服器預覽，可於終端機執行：
     ```powershell
     cd D:\稜鏡媒體網站\Demo
     python -m http.server 8080
     # 瀏覽 http://127.0.0.1:8080
     ```

## 🎯 客戶展示亮點與功能指引

展示時可依下列五大流程向客戶依序示範：

### 1. 示範案例展示（體驗「相反主張」的科學判定）
- 點選左上角切換為「**示範案例**」。
- 畫面會載入「市中心汽車通行費提案」事件。
- **亮點說明**：
  - 文章 A（交通研究者，支持 $+2$）與文章 B（商圈代表，反對 $-2$）在「主張方向」維度分數相反，差距達 $4$，雙方信心皆達 $100\%$。
  - 系統上方自動亮起橙色警示標籤：**「辨識到相反主張」**。
  - 下方「討論焦點」與「表達方式」維度同時並存，直觀呈現兩人聚焦制度（焦點一致），但態度對立。

### 2. 真實新聞觀察（聯合新聞網 RSS 樣本）
- 點擊左側「**真實新聞**」按鈕，可即時切換至真實政治時事議題：
  - **蔣得立入學與身分爭議**
  - **中火燃氣機組都審爭議**
  - **陳其邁政績與跨市政治交鋒**
- **亮點說明**：
  - 稜鏡**不以特定政治立場預設標籤**，未經核對的新聞主張方向皆保留「待判定」；
  - 呈現平衡的新聞觀察工作台視角，避免 AI 幻覺或主觀偏見。

### 3. 動態觀點地圖（Perspective Map）
- 每個維度均具備動態刻度軸（$-2 \sim +2$），文章 A（藍色）與文章 B（橙色）定位標記清楚標示。
- 點擊「**查看判定依據與引文**」可展開折疊抽屜，查閱雙方具體引述文字、判定理由與評定方式。

### 4. 報導時間軸（Chronological Timeline）
- 切換至「**報導時間軸**」分頁，依發布先後順序串聯事件報導（標示台北時間）。
- 支援直接點擊「**選為 B 比較 →**」，即時更換比較對象並返回地圖。

### 5. 人工覆核與標註互動（Review Modal）
- 點擊任一文章卡片或時間軸上的「**標註覆核**」按鈕。
- 彈出「為主張留下依據」專業彈窗，展示包含方向評分、信心水準、主張者、依據引文與判定理由等 5 大欄位。
- 在展示中修改數值並點擊「儲存標註與更新地圖」，觀點地圖上的標記與對立狀態會**即時動態更新**，向客戶展現完整的數據閉環！
